# 神经科学启发的有界运行时：第一阶段设计

## 目标与非目标

目标是在固定资源预算内，根据任务动态选择工作模块/权重块，并复用有限槽位；任务状态和长期经验独立于临时工作集。首阶段先实现可测试的资源调度抽象和遥测契约，再接入真实推理后端。

非目标：不宣称复刻大脑、不把路由分类器等同于神经元跳算、不把元数据槽位模拟等同于实际 RAM 降低，也不在没有后端支持时任意拼接 Transformer 层。

## 生物原则到工程机制

| 原则 | 工程映射 | 可验证指标 |
|---|---|---|
| 注意/任务相关激活 | 路由器只选择当前任务候选集 | 选择准确率、无效加载数 |
| 工作记忆容量有限 | 固定字节预算和固定槽位池 | 槽位数、准入字节、峰值 PSS |
| 神经资源复用 | LRU/显式优先级替换，复用现有槽位 | 驱逐次数、切换延迟 |
| 记忆巩固的抽象 | 任务临时轨迹与持久经验分离 | 未验证经验写入数必须为 0 |
| 预测与反馈 | 预测下一任务资源，按实测结果更新 | 预测命中率、错误预取成本 |

这些是功能类比，不是生物机制的一一对应。

## 初始组件

1. 常驻调度器：轻量、确定性、可回退；读取任务特征、设备预算和模块目录。
2. 固定容量工作集：槽位数与字节预算在启动时设定；新候选必须先通过准入检查，不能通过扩容绕过上限。
3. 模块目录：只保存模块 ID、兼容性、磁盘位置、大小、校验和、能力标签，不预先加载所有候选权重。
4. 任务状态：计划、检查点、验证结果放在独立状态存储中，模块被驱逐后任务仍可恢复。
5. 反馈与巩固：未知结果不作为训练标签；只有独立验证通过的经验进入持久策略集。
6. 后端适配层：必须报告真实的加载/卸载、权重驻留、计算路径和整应用 PSS。若后端无法卸载权重，路由只能作为策略实验，不能声称节省模型内存。

## 重要的模型结构限制

普通稠密 Transformer 每生成一个 token 通常都要经过全部层。按层流式载入可以限制权重工作集，但可能每个 token 都产生大量磁盘/内存搬运，延迟可能不可接受。MoE 只激活少数专家也不意味着专家权重不会全部驻留。LoRA 可切换，但基础模型内存仍在。

因此按顺序验证：
1. 先测固定模型下的上下文、KV cache、批大小、线程等预算；
2. 评估后端是否支持 mmap/按需页入、可控卸载和实际 PSS 测量；
3. 仅在真实收益可测时研究层/专家/FFN 分组动态计算。

如果 9B 基础权重本身无法在目标设备上满足预算，不能靠卸载小插件解决。必须比较较小常驻模型、权重分页/流式方案，或外部教师离线蒸馏方案。

## 内存准入规则

- Android 整应用硬上限：4096 MiB。
- 4096 MiB 不是目标工作值。需预留系统、UI、后端缓冲、KV cache 与切换峰值空间。
- 任何未知、缺失或非有限的内存测量，都不能授权升档或加载大模块。
- 只有整应用 PSS/峰值指标才能证明整应用约束；子进程 RSS/PSS 不够。
- 资源切换应遵循“先释放/确认释放，再装入”，不得同时保留旧、新权重导致瞬时双倍占用。
- 每次实验记录设备、系统、后端版本、模型哈希、上下文、KV cache、权重驻留、峰值 PSS、切换时间与任务质量。

## 第一阶段完成条件

- [ ] 固定容量资源池具备确定性准入、复用、驱逐和预算拒绝。
- [ ] 单元测试覆盖容量、LRU、固定槽位和全槽位锁定。
- [ ] 9B 教师知识有独立的数据格式、来源追踪、去重与验证流程。
- [ ] 不把 GGUF 当作普通可反向传播的训练权重。
- [ ] 后端集成前，明确标记当前资源池仅是调度抽象，不是实际权重分页实现。
- [ ] Android 实测之前，不宣称达到 4 GiB 目标。
